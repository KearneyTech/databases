# Databases
One repo to rule them all. I can't think of a good way to organize db info my project. I'll be adding all of my scripts and table definitions here. Right now everything is running locally. Adjustments will be made as new environments are spun up.  There are tables for MySQL and PostgreSQL. I expect to add MongoDB later.

This will be the location to collect database best practices and optimizations.

### Docker Commands
**Mysql**  
docker ps  
docker image list  
docker exec -it mysql-local bash  
mysql -uroot -p  
[PASSWORD]  
show databases;  
use [database];  
show tables;  
quit  
exit
